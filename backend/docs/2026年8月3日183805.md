## 四、现在是不是一个可以演示的 Demo

结论是：

> 现在已经是一个可以演示“聊天 + 事件写入 + Consolidate + 记忆读取界面”的集成 Demo，但还不是完整的 Agent Memory Service 闭环 Demo。

目前可以演示：

1. 前端发送消息。
2. Chatbot 调用 DeepSeek。
3. Chatbot 调用 Memory API 读取上下文。
4. 用户和机器人事件写入 PostgreSQL。
5. Working Memory 写入 Redis。
6. 触发 Consolidate Once。
7. 生成 Evidence、TaskCheckpoint 和 LongTermCandidate。
8. 前端查看调试结果。

目前不能可靠演示：

```
长期候选
→ 自动治理
→ active 长期主记录
→ exact/vector/graph 索引
→ 后续对话稳定召回
→ 生命周期治理
→ 用户完整删除
```

此外，Chatbot 自己使用 SQLite 保存聊天历史。因此“机器人记得上一轮对话”不一定代表 Memory Service 长期记忆已经成功工作，可能只是 SQLite 对话历史在发挥作用。后续验收必须明确区分这两种来源。
