# 用户画像字段设计

> 生成日期：2026年8月4日  
> 来源：从 `long_term_memory` 表中的 FACT / PREFERENCE / CONSTRAINT / DECISION / PROGRESS 五类记忆提取  
> 说明：本文档定义用户画像应包含哪些字段及其数据来源，不涉及表结构设计

用户偏好，反馈，项目事实，参考信息；针对ai编程

---

## 一、设计原则

1. **画像从记忆中提取**：所有字段来源于 `long_term_memory` 表，不独立采集
2. **画像只存摘要**：不复制记忆正文，只存提炼后的结构化字段
3. **画像可回溯**：每个字段关联 `memory_id`，可追溯到原始记忆和证据链
4. **画像自动更新**：新的记忆进入主记录后，画像字段自动合并/更新
5. **画像有置信度**：每个字段带 confidence，反映信息可信程度

### 一、身份信息（3 个字段）

## 四、字段与记忆类型的映射关系

```
记忆类型 → 画像字段映射：

FACT (事实)
  ├── display_name, email, phone, other_contacts
  ├── job_title, company, department, seniority_level, role_description
  ├── technical_skills, domain_expertise, tools_and_platforms
  ├── team_members, collaborators, reporting_line
  ├── current_project, project_history
  └── timezone

PREFERENCE (偏好)
  ├── preferred_language
  ├── communication_style, work_habits, learning_preferences
  ├── notification_preferences
  └── timezone (如果以偏好形式表达)

CONSTRAINT (约束)
  ├── time_constraints
  ├── resource_constraints
  ├── process_constraints
  └── notification_preferences (如果以约束形式表达)

DECISION (决策)
  ├── recent_decisions
  ├── technology_decisions
  ├── pending_decisions
  └── role_description (如果以决策形式表达)

PROGRESS (进展)
  ├── current_project
  ├── project_history
  ├── active_task_ids
  └── recent_milestones
```

## 五、字段值的通用结构

每个画像字段值统一采用以下结构，保证可追溯性：

```json
{
  "<字段名>": {
    "value": "<实际值>",
    "confidence": 0.85,                          // 该字段的综合置信度
    "source_memory_id": "memory_xxx",             // 主要来源记忆 ID（单值字段）
    "source_memory_ids": ["memory_xxx", "..."],   // 所有来源记忆 ID（列表字段）
    "last_updated_at": "2026-08-04T10:00:00Z",   // 该字段最后更新时间
    "evidence_count": 3                           // 支撑该字段的记忆数量
  }
}
```

## 六、提取优先级

当多条记忆涉及同一字段时，按以下优先级选取：

1. **显式度（explicitness）高者优先**：用户明确说"我叫张三" > 从签名推断
2. **置信度（confidence）高者优先**：0.95 > 0.7
3. **时间新者优先**：最近说的 > 很久以前说的
4. **DECISION > PREFERENCE > FACT**：用户决定的事 > 偏好 > 一般事实
5. **冲突时标记**：两条矛盾信息同时存在时，保留两条并标记为 `conflict`

## 七、更新策略

| 触发条件 | 更新范围 | 策略 |
|---------|---------|------|
| 新 FACT 记忆进入主记录 | 身份/职业/技能/项目 相关字段 | 增量追加或覆盖 |
| 新 PREFERENCE 记忆进入主记录 | 偏好/习惯 相关字段 | 追加到列表，旧偏好不自动删除 |
| 新 CONSTRAINT 记忆进入主记录 | 约束 相关字段 | 追加到列表 |
| 旧记忆被 SUPERSEDE | 关联字段 | 更新为该记忆的新版本 |
| 旧记忆被 ARCHIVED | 关联字段 | 标记为"已过期来源"，重新评估字段值 |
| 定期（每天） | 聚合统计字段 | 重新计算 avg_confidence 等统计值 |
| 手动触发 | 全量 | 重新扫描该用户全部 active 记忆重建画像 |

| 上下文感知推荐 | technical_skills, domain_expertise, current_project |
| 冲突检测 | time_constraints, resource_constraints |
| 决策追溯 | recent_decisions, technology_decisions |
| 团队协作 | team_members, collaborators, reporting_line |
| 画像摘要 | persona_summary |
